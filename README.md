<h1 align="center">PDFácil</h1>

**PDFácil** é um aplicativo desktop gratuito e completo para manipular, editar, mesclar, converter e processar arquivos PDF. Todo o processamento acontece localmente na sua máquina — seus arquivos nunca saem do seu computador.

Construído com [Tauri](https://tauri.app/), combina uma interface web moderna com a performance e segurança de um app nativo.

---

## Por que PDFácil?

- **Privacidade total**: Todo processamento é local. Seus arquivos nunca são enviados para nenhum servidor.
- **Sem limites**: Manipule quantos arquivos quiser, sem restrições.
- **Sem internet**: Funciona 100% offline após a instalação.
- **Gratuito e open-source**: Código aberto para todos.

## Como Usar

### Pré-requisitos

- [Node.js](https://nodejs.org/) v18+
- [npm](https://www.npmjs.com/)
- [Rust](https://www.rust-lang.org/tools/install) (para compilar o app Tauri)
- Pré-requisitos do Tauri para o seu sistema operacional — veja [TAURI.md](TAURI.md)

### Desenvolvimento

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/PDFacil.git
cd PDFacil

# Instale as dependências
npm install

# Inicie o app desktop em modo de desenvolvimento
npm run tauri:dev
```

### Build para Produção

```bash
# Compile o aplicativo desktop (gera MSI no Windows, DMG no macOS, AppImage no Linux)
npm run tauri:build
```

O instalador será gerado em `src-tauri/target/release/bundle/`.

## Stack Técnica

- **Tauri 2** — Framework para apps desktop com frontend web
- **Vite** — Build tool rápido para desenvolvimento web
- **TypeScript** — Tipagem estática
- **Tailwind CSS** — Estilização da interface
- **pdf-lib** — Manipulação de PDFs no cliente
- **pdfjs-dist** — Renderização de PDFs (Mozilla)
- **qpdf-wasm** — Operações avançadas via WebAssembly
- **tesseract.js** — OCR (reconhecimento óptico de caracteres)

## Contribuindo

Contribuições são bem-vindas!

1. Faça um fork do repositório e crie sua branch a partir de `main`.
2. Siga os passos de **Como Usar** para configurar o ambiente.
3. Faça suas alterações e commite com uma mensagem clara.
4. Abra um **Pull Request** descrevendo suas mudanças.

Estilo de código aplicado via Prettier (2 espaços, aspas simples, vírgulas trailing ES5).
